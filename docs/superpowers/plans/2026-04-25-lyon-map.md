# Lyon Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a new `public/lyon-map.html` interactive Leaflet map to identify the best places to live in Lyon + nearby communes, based on Actu.fr (20 communes scored /100) and CityCrunch (arrondissement opinions mapped to a numeric scale).

**Architecture:** A static HTML page (same UI style as `public/france-map.html`) that loads a small JSON dataset describing communes + arrondissements (name, coords, scores, explanations, source links), renders markers with source-aware styling, and provides a right-side panel with a Top list and details on selection.

**Tech Stack:** Static HTML + CSS + vanilla JS, Leaflet, optional Nominatim geocoding script (Node https).

---

## File structure (locked)

**Create:**
- `public/lyon-map.html` — Leaflet map UI (legend, filters, tooltips, panel), style aligned with `france-map.html`.
- `public/lyon-data.json` — dataset consumed by `lyon-map.html` (copied from `map-data/lyon-zones.json` for GH Pages hosting).
- `map-data/lyon-zones.json` — source dataset (same contents as `public/lyon-data.json`).
- `scripts/build-lyon-data.js` — copies `map-data/lyon-zones.json` → `public/lyon-data.json` and stamps build time.
- `scripts/geocode-lyon-zones.js` — optional helper to geocode items via Nominatim (rate-limited; identifiable UA).

**Modify (small):**
- `package.json` — add `build:lyon`, `geocode:lyon` and optionally `build:all` chaining.
- `public/index.html` or `public/france-map.html` — add a nav link to `lyon-map.html` (choose one consistent place).
- `README.md` — add “Carte Lyon” section with commands.

## Task 2: Geocode all items via Nominatim (rate-limited)

**Files:**
- Create: `scripts/geocode-lyon-zones.js`
- Modify: `map-data/lyon-zones.json`

- [ ] **Step 1: Create `scripts/geocode-lyon-zones.js`**

Requirements:
- Reads `map-data/lyon-zones.json`, loops `items[]` missing `lat/lng`.
- For **communes** query examples:
  - `Écully, Métropole de Lyon, France`
  - If miss, fallback: `Écully, Rhône, France`
- For **arrondissements** query examples:
  - `Lyon 1er arrondissement, France`
  - `Lyon 2e arrondissement, France` etc.
- Writes back file with:
  - `lat`, `lng`
  - `geocode`: `{ status: "ok"|"miss", query, displayName, placeId }`
- Politeness:
  - 1 req/s minimum, configurable with `NOMINATIM_DELAY_MS`
  - identifiable UA via `NOMINATIM_UA` env, and optional `NOMINATIM_EMAIL`

Use the same helper style as `scripts/geocode-mtb-downhill-curated-fr.js` (https + sleep + search endpoint).
